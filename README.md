# 🥋 Salle de l'Esprit et du Temps — NSI Terminale

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/SamiChabbi/salle-de-l-esprit-et-du-temps-eleve/main)

Une salle d'entraînement pour trois chapitres de Terminale NSI : **la récursivité**, **diviser pour régner** et **la programmation orientée objet**.

## Le principe

Pour chaque chapitre, on a rassemblé une **base d'exercices tombés pour de vrai** : épreuve écrite du bac (2021 à 2025), épreuve pratique du bac, et contrôles de Terminale publiés par des professeurs. Chaque question a été rangée dans un **type** (ce qu'on te demande vraiment). Le cours de chaque chapitre est tiré de cette analyse : **ce qui tombe, et comment répondre à chaque type de question.**

Chaque notebook a deux parties :
1. **La méthode** : ce qui tombe le plus, une méthode en 5 étapes, une fiche par type de question (comment la reconnaître, la méthode, un exemple, les pièges), et une fiche réflexe ;
2. **Les exercices**, du plus simple au plus difficile. Chaque question porte une étiquette 🏷️ qui te dit quelle fiche utiliser.

## Contenu

```
01_Recursivite.ipynb            19 exercices
02_Diviser_pour_regner.ipynb    16 exercices
03_POO.ipynb                    20 exercices
```

## Comment travailler

1. Lire la Partie 1 (la méthode) une première fois.
2. Faire chaque question **sur papier** d'abord, en suivant la fiche indiquée par l'étiquette 🏷️.
3. Recopier son code dans la cellule prévue, puis lancer la cellule **🧪 Tests** : `✔ Tous les tests passent` = gagné.
4. Pour les questions marquées ✍️, écrire la réponse en français dans la cellule prévue.

## Utilisation

- En ligne, sans rien installer : cliquer sur le badge **Binder** ci-dessus.
- Sur son ordinateur : ouvrir les notebooks avec Jupyter (ou VS Code), Python 3 standard, aucune bibliothèque à installer.
